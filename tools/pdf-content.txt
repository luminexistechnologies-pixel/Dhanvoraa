2. How It Works
l
Explain the customer journey in simple language.
l
Step 1: Choose the savings option.
l
Step 2: Enter the amount / complete the transaction through the Augmont flow.
l
Step 3: Track the digital holding through the provided platform.
l
Step 4: Use available sell/redemption/physical delivery options as supported by Augmont.
l
Do not recreate Augmont's operational functionality on the Dhanvora website.
3. Start Saving / CTA Button
l
A clearly visible “Start Saving” button should be available on the Home Page and relevant sections.
l
The button should open the Augmont-provided placeholder or integration.
l
The exact integration method must follow Augmont's technical instructions.
l
If Augmont provides an iframe/embed code, use the supplied code as instructed.
l
If Augmont provides a URL, redirect the customer to that URL.
l
If Augmont provides a JavaScript/widget integration, implement the supplied integration code.
l
Do not hard-code assumptions about the Augmont integration until their final integration details are received.
4. Gold / Silver Information
l
Simple explanation of digital gold/silver savings.
l
Explain that customers can start with small amounts, subject to the applicable Augmont terms.
l
Display only current pricing, minimum amounts, charges, taxes, redemption details and other operational
information supplied/approved by Augmont.
l
Avoid making investment-return or guaranteed-profit claims.
